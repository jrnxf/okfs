# Gauge archive

One file a day per gauge, with a reading every ten minutes:
`<station>/<year>/<month>/<YYYY-MM-DD>.csv`.

- Heights are in metres above chart datum, with each gauge's offset already taken off
- A day with no file is a day the gauge was down
- `summary.json` in each month holds the highs, lows and ranges
