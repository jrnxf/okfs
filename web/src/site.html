A file browser for any folder you can reach.

Run okfs in a folder and your browser opens on it. The list sits on the left. The file under the cursor shows beside it as soon as the cursor lands, so holding j flips through a folder of photos, PDFs or video.

  • Runs onLinux, macOS
  • Ships asone binary, about 18 MB
  • Serves at127.0.0.1:8080
  • Deletes filesonly with --allow-delete

      In the box

      What okfs does

      01Previews
      Pictures, video, sound, PDFs, Markdown, code, CSV, JSON, zip files and web pages, each shown as itself.
      02Search
      Ctrl K finds any name in the tree. The query lives in the address, so a shared link keeps it.
      03Columns
      A folder under the cursor shows what is in it, and the columns slide as you go in and out.
      04Live
      A file added, removed or rewritten shows at once, without a reload.
      05Your phone
      okfs --bind 0.0.0.0 --qr prints a QR code for another device on the network.
      06Self-contained
      The page is compiled into the binary. Nothing is fetched from another site.

      Questions

      Questions

      How do I browse a folder in my browser?

      Run okfs in it. It serves the folder at http://127.0.0.1:8080 and opens your browser on it.

      Is okfs an alternative to python -m http.server or miniserve?

      Yes, for looking at files. It adds previews, a search of the whole tree and live updates, and stays read only. For uploads, use dufs or copyparty.

      How do I open files from my computer on my phone?

      okfs --bind 0.0.0.0 --qr prints a QR code with a secret link. Scan it on a phone on the same network.

      Can visitors upload, edit or delete files?

      There is no upload and no editing. Deleting needs --allow-delete.

      Does okfs need Docker, a database or an account?

      No. It is one binary with the page inside it.

      Does it run on Windows?

      Not yet. It runs on Linux and macOS.

      How to install
      nix run github:jrnxf/okfs -- ~/photos
      nix profile install github:jrnxf/okfs

      The first line runs it once in ~/photos. The second puts it on your PATH; nix profile upgrade okfs updates it.

      tag=$(gh release list --repo jrnxf/okfs --limit 1 --json tagName --jq '.[0].tagName')
      gh release download "$tag" --repo jrnxf/okfs --pattern '*-aarch64-apple-darwin.tar.gz*'
      tar -xzf okfs-*-aarch64-apple-darwin.tar.gz

      That is a Mac with Apple silicon; the binary is okfs in the folder the archive makes. For an Intel Mac ask for x86_64-apple-darwin, for Linux x86_64- or aarch64-unknown-linux-musl. Each archive holds completions and a man page. The first release, v0.1.0-pre.1, is on its way.

      cargo install --git https://github.com/jrnxf/okfs
      okfs ~/photos

      It needs a Rust toolchain and bun, which builds the page.
