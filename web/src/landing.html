Previews

Pictures, film, sound, pages and code.

A file shows as soon as the cursor is on it, in the same pane. Markdown, SVG and JSON open as their source, colored and never run; r flips them to what they make. HTML is sandboxed in an origin of its own.

Themes

One CSS file per theme.

Five built in, light and dark, switchable from the palette. A theme sets 42 tokens and nothing else, and okfs theme check holds it to the contract: contrast included.

One binary

Nothing to install beside it.

The page is compiled into okfs, so nothing is fetched from another site while it runs. It is read only until you say otherwise, and it follows the folder: a file that changes on disk shows at once, with no reload.

How this page works

The real thing, in your tab.

There is no server behind this page. Here is exactly what is okfs, and what is drawn for the demo.

Real okfs

  • The page: okfs's own interface from its source, as it ships in the binary
  • The index: src/index.rs compiled to WebAssembly. It walks the folder, leaves out node_modules and what .gitignore and .okfsignore name, and answers every search, every recent list and every count
  • The listings: okfs's code for a folder's entries, with its sorting and hidden files

Recorded, or made for the demo

  • Previews of text: the Markdown, code, tables and JSON as a real okfs drew them, for the tidewater files and one file of each kind that the others borrow
  • The demo folder itself is made up: this page builds it, and draws its pictures and its bell, in your browser from a seed

Only on your machine

  • Your own files, with their own contents: here many names share one film, one PDF and one sound
  • Thumbnails, the first page of a PDF as a picture, zips of folders, and deleting
  • Search on every core: here it runs on one thread
Install

Run it in a folder.

With nix, run it without installing anything. On x86-64 Linux, each release has the binary on its own. From a checkout, cargo builds it.

nix run github:jrnxf/okfs -- ~/photos
nix profile install github:jrnxf/okfs
gh release download --repo jrnxf/okfs --pattern 'okfs-x86_64-unknown-linux-gnu*'
cargo install --path . # in a checkout, with bun on the PATH
